# 모으미

여러 대외활동을 준비하는 대학생이 모집글을 붙여넣거나 포스터를 올리면, AI가 핵심 정보와 일정을 정리해 마감일순 공고 목록을 만들 수 있는 서비스입니다. [모으미 열기](https://moeumi.vercel.app/archive)

## 세 화면에서 할 수 있는 일

- **저장 목록**에서 **+ 모집공고 추가**를 누르고 본문이나 포스터 사진을 최대 3장까지 넣으세요. **AI로 정리하기**를 누른 뒤 활동명과 날짜를 검수해 저장하거나 직접 입력할 수 있습니다. 파스텔색 카테고리 탭으로 공고를 골라 보고, 지원을 마치면 **지원 완료**를 체크하세요. 마감이 지난 공고는 목록 아래에 모입니다. **전체 → 편집**에서는 정렬 방식과 삭제할 공고를 선택한 뒤 **적용**으로 확정합니다.
- **메모장**에는 준비할 서류나 면접 질문을 색깔별 메모로 적으세요. 메모는 자동 저장되며, 공고에 연결하거나 내용으로 검색할 수 있습니다.
- **지원서 매니저**에서는 지원서 폼을 붙여넣고 **AI로 나누기**를 누르면 질문과 세부 요구사항을 검수할 수 있습니다. 질문을 직접 추가할 수도 있습니다. 답변을 쓰면서 글자 수와 완료 여부를 확인하고, 작성한 내용을 복사하거나 텍스트 파일로 내려받으세요.

## 저장과 AI 전송

공고·메모·지원서는 현재 브라우저의 사이트 저장소에 보관됩니다. 같은 주소와 브라우저 프로필로 다시 열면 이어서 쓸 수 있습니다. 다른 기기나 주소에는 자동으로 공유되지 않으며, 사이트 데이터를 지우면 저장한 내용도 지워집니다.

공고를 AI로 정리할 때는 모집글 본문과 첨부 사진을, 지원서 폼을 AI로 나눌 때는 붙여넣은 폼 텍스트를 Google Gemini에 보냅니다. 출처 메모·메모장 내용·작성한 답변은 이 브라우저에만 저장됩니다.

## 내 컴퓨터에서 실행하기

Node.js 24와 pnpm 11 환경에서 저장소의 `moeumi/` 폴더로 이동해 필요한 패키지를 설치하고 개발 서버를 시작하세요.

```sh
cd moeumi
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시된 주소의 `/archive`를 여세요. AI 기능을 사용하려면 `moeumi/.env.example`을 같은 폴더의 `.env.local`로 복사하고 서버용 `GEMINI_API_KEY`를 설정하세요. 모델은 `GEMINI_MODEL`로 지정할 수 있습니다. `.env.local`은 Git에서 제외됩니다.

`moeumi/`에서 `pnpm test`로 기존 자동 검사를, `pnpm build`로 타입 검사와 배포용 빌드를 실행합니다. 기능별 시나리오와 알려진 문제는 [QA 기록](QA.md), 제품 기준은 [요구사항 문서](PRD.md)에서 확인할 수 있습니다.
