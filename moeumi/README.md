# 모으미
모집공고의 본문과 포스터를 검수 가능한 초안으로 정리합니다. 공고 아카이브에서 관심 공고를 비교하고, 상단 추가 버튼으로 새 공고를 입력합니다.

## 실행
Node.js 24와 pnpm 11 환경에서 프로젝트 폴더를 열고 실행하세요.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

개발 서버의 `/archive`에서 앱을 엽니다. 이전 플래너·서가 주소도 아카이브로 연결됩니다. 텍스트·포스터 AI 추출은 `.env.example`을 `.env.local`로 복사하고 사용 가능한 서버 전용 `GEMINI_API_KEY`와 `GEMINI_MODEL`을 설정한 뒤 서버를 다시 시작하세요. 직접 입력은 키 없이 사용할 수 있습니다. AI 정리 시 입력 자료는 서버를 통해 Gemini로 전송합니다.

## 검증과 배포
`pnpm test`로 날짜·저장 호환·API 검증을, `pnpm build`로 타입 검사와 프로덕션 빌드를 실행합니다. Vercel 프로젝트 루트는 이 폴더로 설정하고 환경 변수를 서버에 등록하세요. Vite 빌드는 `dist/`에, Sites용 Worker는 `dist/server/index.js`에 생성됩니다.

## 저장과 날짜
공고는 현재 브라우저의 `campus_deadline_rows_v1`에 보관합니다. 저장 이력이 없는 브라우저에는 수정·삭제 가능한 예시 한 건이 추가됩니다. 요약은 전체 목록을 기준으로 합니다. 마감은 한국 시간으로 계산하며 임박 집계는 예시를 제외하고 오늘부터 7일 뒤까지 포함합니다. 같은 마감일의 공고는 최근 저장 순입니다.
